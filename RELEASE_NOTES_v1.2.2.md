Release v1.2.2 - Reports PDF branding parity

Summary
-------
This patch brings the PDFs generated by the "Reports & Exports" section into visual parity with the Farm Report Card PDFs. The exports now include the farm banner image, the farm name as the primary title (or "Chicken Tracker" if not set), a subtitle with the report name, warm cream/brown theming, summary stat cards, styled tables with brown headers and alternating rows, and a matching footer.

Files changed
-------------
- lib/core/services/pdf_export_service.dart
  - Added shared header/footer/table/stat-card helpers
  - Rewrote Production, Sales, Expenses, Flock Purchases, and Flock Losses PDF generators to use the Farm Report Card style
  - Threaded `farmName` through `generatePdf()` to show the configured farm name on the banner

- lib/features/reports/screens/reports_screen.dart
  - Passes `farmNameProvider` value to `PdfExportService.generatePdf()` when exporting

Other changes
-------------
- pubspec.yaml version bumped to 1.2.2+5

Upgrade notes
-------------
No migration required. After pulling this release, run the app as usual. If you regenerate any code or assets, run:
